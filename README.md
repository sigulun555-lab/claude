# TikTok アフィリエイト コンテンツ自動ドラフト生成

ガジェット・便利グッズ ジャンルのTikTokアフィリエイト向けに、毎日
「トレンドリサーチ → CapCutにそのまま貼り付けられる台本 → キャプション/
ハッシュタグ」の**下書き**を自動生成する仕組みです。追加のAPI課金は
発生しません(Claude Codeの定期実行の範囲内で完結します)。

## 2つのフェーズ

TikTok Shopアフィリエイトはフォロワー1,000人以上が条件のため、
`config/phase.txt` でフェーズを切り替えます。

| フェーズ | `phase.txt`の値 | 内容 |
|---|---|---|
| 成長期(デフォルト) | `growth` | アフィリエイトリンクなし。バズりやすいガジェット紹介でフォロワーを増やす台本 |
| 収益化期 | `monetization` | TikTok Shop商品紹介+アフィリエイトリンク前提の台本 |

フォロワーが1,000人を超えたら、`config/phase.txt` の中身を
`growth` から `monetization` に書き換えてコミットしてください
(次回の自動生成から反映されます)。

## 毎日の下書きの中身

`content/<日付>/<ジャンル>/` に3ファイル生成されます。

- `research.md` — トレンド商品リサーチ(根拠URL付き)
- `script.md` — 2部構成
  - 「CapCutナレーション原稿」: そのままCapCutのAI音声(テキスト読み上げ)欄に
    コピペできるプレーンテキスト
  - 「構成メモ」: どのタイミングでどの映像を映すかの参考メモ
- `caption.md` — 投稿キャプション文言 + ハッシュタグ(`#PR`表示込み)

## あなたが毎日やること(CapCutでの組み立て、無料)

1. `content/` フォルダで今日の下書きを開く
2. CapCut(無料アプリ)を開き、新規プロジェクトを作成
3. 商品の映像・画像を用意する
   - 成長期: フリー素材やご自身の手元映像でOK
   - 収益化期: TikTok Shopのクリエイターマーケットプレイスで、出品者が
     用意している商品動画・画像素材をダウンロードして使う
4. `script.md` の「CapCutナレーション原稿」をCapCutのテキスト読み上げ
   (AI音声)機能に貼り付けて音声を生成
5. 自動字幕機能で字幕をつける
6. **王冠マーク(Pro限定)のついたテンプレート・エフェクトは使わない**
   → これを守れば無料版のままウォーターマークなしで書き出せる
7. `caption.md` の文言・ハッシュタグをそのまま投稿欄にコピペして投稿
