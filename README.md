# TikTok アフィリエイト コンテンツ自動ドラフト生成

ガジェット・便利グッズ ジャンルのTikTokアフィリエイト向けに、毎日
「トレンドリサーチ → 動画台本 → キャプション/ハッシュタグ」の**下書き**を
自動生成する仕組みです。

## 仕組み(追加課金なし)

Anthropicの有料API(従量課金)は使いません。代わりに、Claude Codeを
決まった時刻に自動で起動する「Routine(定期実行)」を使い、Claude Code
自身が直接このリポジトリにファイルを作成・コミットします。追加のAPIキー
登録やクレジットカード登録は不要です(既存のClaude Codeの利用枠の中で
動きます)。

## 何が自動化されていて、何が手動なのか

| 工程 | 自動 / 手動 |
|---|---|
| ジャンルのローテーション | 自動(`config/niches.txt`を日替わりで選択) |
| トレンド商品リサーチ・下書き作成 | 自動(毎日、Claude Codeの定期実行) |
| リポジトリへのコミット | 自動 |
| 内容の事実確認・最終チェック | **手動**(あなたのレビュー) |
| TikTok Shop / ASPへのアフィリエイト提携 | **手動**(あなた自身の申請が必要) |
| 実際の動画撮影・投稿・広告表示(#PR等) | **手動** |

このリポジトリは「量産・下書き」までを担当します。投稿・提携・課金など
実世界に影響する行為は行いません。

## ジャンルの調整

`config/niches.txt` の各行がローテーション対象のジャンルです。
自由に追加・編集してください。

## 法令・規約に関する注意

- 生成されるキャプション案には景品表示法のステマ規制に対応した
  `#PR` 等の広告表示を含めるよう指示していますが、
  **投稿前に必ず人間が内容を確認してください**。
- TikTok Shop / 各ASPの利用規約・審査は本リポジトリの範囲外です。
  提携申請はご自身で行ってください。
- 生成内容に実在しない実績やレビューを作らせないよう指示していますが、
  最終的な事実確認の責任はご自身にあります。
