# note向け記事生成エンジン(お金・副業・投資ジャンル)

「お金・副業・投資」ジャンルのnote記事のドラフトを継続的に生成するための仕組みです。
**完全無人で収益が発生し続ける仕組みではありません。** noteには投稿用の公開APIが
無いため、生成した記事をnoteに貼り付けて投稿する作業は手動で行う前提です
(規約に反する自動投稿・スクレイピングは行いません)。

## できること / できないこと

**できること**
- テーマのローテーション管理(`topics.json` / `used_topics.json`)
- Claude APIを使った記事ドラフトの自動生成(無料部分+有料部分の構成、タグ、想定価格まで)
- 生成したMarkdownをnoteのエディタにそのまま貼り付けられる形式で出力

**できないこと(人の作業が必要)**
- noteへの実際の投稿(コピー&ペーストで手動投稿してください)
- noteアカウントの有料設定・価格設定の最終確定
- 収益の保証(需要・競合・読者反応次第です)

## セットアップ

```bash
cd content_engine
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # ご自身のAnthropic APIキー
```

## 使い方

```bash
# 1本生成
python generate_articles.py --count 1

# まとめて3本生成(毎日投稿するストックを作る場合など)
python generate_articles.py --count 3
```

生成された記事は `output/articles/YYYY-MM-DD-スラッグ.md` に保存されます。
中身をひと通り読んで事実確認・言い回しの調整をしてから、noteに貼り付けて投稿してください。

`topics.json` にテーマを追加すれば、ネタ切れを防げます。使用済みテーマは
`used_topics.json` で管理され、全テーマを使い切ると自動的にローテーションし直します。

## 記事の構成ルール

生成される記事は以下のルールに従うよう、システムプロンプトで制御しています(`generate_articles.py` 内の `SYSTEM_PROMPT`)。

- 特定の金融商品・銘柄・副業案件を名指しで推奨しない
- 「絶対儲かる」など断定的・誇大な表現を使わない
- 投資には元本割れリスクがあることに必ず触れる
- 無料部分(悩みへの共感+概要)と有料部分(具体的な手順)に分けて構成
- 記事末尾に免責事項・タグ・想定販売価格を含める

これは「お金・投資」ジャンルの記事が金融商品取引法・景品表示法などに触れるリスクを
下げるための最低限のガードレールです。実際に投稿する前に、内容が適切かどうかは
必ずご自身でも確認してください。

## サンプル記事

`output/articles/` に、動作イメージをつかむためのサンプル記事を2本置いています。

- `2026-09-10-会社員が始めやすい副業の選び方.md`
- `2026-09-10-新NISAの基本と非課税枠の使い方.md`

## 運用イメージ(毎日投稿したい場合)

1. 週末などにまとめて `--count 7` で1週間分を生成
2. 生成された記事を確認・微調整
3. 毎朝1本ずつnoteに手動投稿(スマホからのコピペでも数分で完了)
4. 反応が良かったテーマの傾向を`topics.json`にフィードバックして改善する

cron やGitHub Actionsで「生成」までは自動化できますが、「note投稿」は
安全のため手動ステップとして残すことを推奨します。
