# チャリロト5 予想アプリ

チャリロト5は、その日に行われるレースのうち**最終競走から数えて5つのレースの1着(単勝)をすべて当てる**くじです(1口100円、キャリーオーバーあり、払戻は売上の75%+キャリーオーバーを的中口数で割った額、上限6億円)。

このフォルダには、過去の結果から作った予想モデルと、ブラウザで動く予想アプリが入っています。

## 使い方

`app/index.html` をブラウザで開くだけで動きます(インターネット接続はフォントの読み込みにだけ使います)。

1. **出走内容を入れる**: 5レースそれぞれに、車立て・各車の級班・並び(周回予想)を入れます。並びはラインごとに `/` で区切ります。例: `1 5 / 2 6 / 8 7 3 / 4 9`
2. **1着になる確率**: 各車が1着になる確率が出ます。
3. **買い方を決める**: 「予算から決める」なら点数の上限を、「的中率から決める」なら目標の的中率を選ぶと、各レースで何車を押さえるかを自動で選びます。
   - 予算モード: 点数の上限の中で、5レース全的中の確率がいちばん高い組み合わせ
   - 的中率モード: 目標の的中率に届く中で、いちばん安い組み合わせ

過去の開催を読み込むと、実際の1着も表示されるので答え合わせができます。

## 予想ロジック

条件付きロジットモデルです。各選手に次の特徴から得点をつけ、同じレースの中で確率に直します(合計100%)。

| 特徴 | 1着へのなりやすさ(1番車・先頭・級班最上位を1とした倍率) |
|---|---|
| 車番 | 2番車 0.73倍、6番車 0.12倍、8番車 0.24倍 など。1番車がいちばん強い |
| ラインの位置 | 番手 0.68倍、3番手以降 0.18倍、単騎 0.92倍 |
| 級班 | 最上位より1つ下 0.70倍、2つ以上下 0.36倍 |
| ラインの人数 | 3人以上のラインは 1.79倍 |

重みは `data/model.json` にあります。正則化の強さは1日抜き交差検証で選びました。

## 検証結果(過去25開催・125レース)

予想する日のデータを学習に使わない「1日抜き交差検証」で確かめた結果です。

- 1レースで確率がいちばん高い選手が1着になった率: **28%**(でたらめに選ぶと約14%)
- 5レース全部の的中率は、点数を増やせば上がりますが、費用も増えます

| 点数の上限 | 見積もり的中率 | 実際に当たった日 | 費用の合計 | 払戻の見込み合計 | 回収率 |
|---|---|---|---|---|---|
| 1点 | 0.3% | 0/25日 | 2,500円 | 0円 | 0% |
| 16点 | 2.9% | 0/25日 | 39,900円 | 0円 | 0% |
| 64点 | 7.7% | 1/25日 | 156,600円 | 6,450円 | 4% |
| 243点 | 17.9% | 3/25日 | 600,600円 | 42,212円 | 7% |
| 500点 | 26.4% | 7/25日 | 1,214,400円 | 383,212円 | 32% |
| 1,000点 | 38.0% | 9/25日 | 2,421,600円 | 608,562円 | 25% |
| 3,000点 | 64.0% | 18/25日 | 7,411,200円 | 3,364,329円 | 45% |

見積もり的中率と実際の的中がおおむね合っているので、確率の出し方は使えると考えています。一方で、**どの点数でも回収率は100%を大きく下回りました**。的中率を90%にするには、例の開催で約9,000点(約90万円)が必要です。100%にするには全通り(7車立てなら16,807点、9車立てなら59,049点)を買うしかなく、キャリーオーバーが大きい日でない限り損になります。

払戻の見込みは「キャリーオーバー+売上×75%」を「他の的中口数+自分の1口」で割った概算です(山分けチャンスなどの上乗せは入っていません)。

## データ

- `data/races.json`: 25開催分の最終5レース(各選手の車番・級班・年齢・期別・着順・決まり手、周回予想の並び、2車単・3連単の払戻)とチャリロト5の結果(売上、的中口数、払戻、キャリーオーバー)
- `data/model.json`: 学習済みモデルの重み
- `data/backtest.json`: 検証結果(点数ごと・開催ごと)
- `data/raw/`: チャリロト.com の結果ページを取得したもの

対象: 奈良・松阪・静岡の 2026-08-14〜2026-10-16 のチャリロト発売日。

## 作り直し方

```sh
python3 scripts/parse_results.py data/raw/*.json > data/races.json  # 結果ページ → JSON
python3 scripts/model.py                                            # 学習と検証 → model.json, backtest.json
python3 scripts/build_app.py                                        # app/template.html にデータを埋め込み → app/index.html
```

`model.py` には numpy が必要です。データを足すときは、チャリロト.com の `https://www.chariloto.com/keirin/results/<場コード>/<日付>` のページを取得して `data/raw/` に置いてください。

## 注意

的中率はモデルの見積もりで、当たることを保証するものではありません。車券の購入は20歳になってから。のめり込みが心配なときは、チャリロト.com の購入限度額の設定を使えます。
