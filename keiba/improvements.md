## 2026-10-13 初回レビュー（実戦前に気づいた構造上の問題）

### 🔴 優先度高（計算結果が大きく狂う）

**1. 複合確度の「足し算」で基礎確度がほぼ無意味になっている** ✅ 2026-10-13 採用（倍率方式＋正規化）
- 基礎確度は2〜5%程度なのに、加算は+7%・+10%など桁違いに大きい。
  例では基礎5.5%に+14%を足して19.5%になっており、確度のほとんどが加算分。
- 同じ加算を全組み合わせにすると、全馬連の確率の合計が100%を大きく超える。
- **改良案**：加算ではなく倍率にする（例：馬場改善 ×1.15、低調 ×0.8）。
  そのあと、レース内の全組み合わせの合計が100%になるよう正規化する。

**2. 基礎馬連的中率の式が他の出走馬を考慮していない** 🔸 一部対応（正規化のみ採用。ハービル式は未採用）
- 「A馬の1着率 × B馬の2着率」は過去の全レースでの率なので、
  今回の相手の強さや頭数が反映されない。
- **改良案**：まず各馬の「今回の勝率」を出し、レース内で合計100%に正規化する。
  そのうえでハービル式 `P(A→B) = pA × pB ÷ (1 − pA)` を使い、
  馬連 = P(A→B) + P(B→A) とする。

**3. 期待値の定義が逆、または混在している** ✅ 2026-10-13 採用（推定確率×オッズに統一）
- STEP10の「100÷オッズ」は期待値ではなく、オッズが示す確率（市場の見立て）。
- STEP10aの「連対率÷オッズが50%以上なら割高」は判定が逆になる
  （確率が高いのにオッズも高い馬こそ割安）。
- **改良案**：期待値 = 推定確率 × オッズ に統一する。
  1.0超なら割安、1.2以上を投資対象にする。
  STEP20の「20%×5倍」は期待値ちょうど1.0（損益ゼロ）なので、基準としては甘い。

**4. ばんえいでは馬場水分の「改善/悪化」の向きが逆** ✅ 2026-10-13 採用
- ばんえいは馬場水分が高いほどソリが滑ってタイムが速くなる
  （重い馬場＝軽い馬場、という逆転が起きる）。
  STEP5の「1.0以上＝脚が重くなる方向で-5%」は、ばんえいには当てはまらない。
- 出力例の「前走1.7稍重→今回1.4重」は、STEP1の区分（1.7＝重、1.4＝稍重）と矛盾している。
- 馬場値（0.6〜3.0などの数値）はばんえい特有のもの。普通の地方競馬は
  良/稍重/重/不良で発表されるので、STEP1の数値区分はばんえい専用にする。
- **改良案**：ばんえいは「水分が高い＝高速馬場」とし、
  評価は「その馬が高速馬場・低速馬場のどちらで好走しているか」の実績で行う。

**5. ばんえいの最重要ファクター「負担重量（ソリ重量）」がない** ✅ 2026-10-13 採用（STEP0d）
- ばんえいは負担重量の増減（数十kg単位）と第2障害の越え方が成績を大きく左右する。
- **改良案**：STEP0に「前走比の重量増減」「馬体重に対する重量の比率」「障害での止まり癖」を追加する。

### 🟡 優先度中（ルールのあいまいさ）

**6. 馬体重ルールに抜けと重複がある**
- -6〜-14kgの扱いが決まっていない。「+10kg以上」と「増量10kg以上で過去になし」が重なる。
- ばんえい（約1,000kg）と普通の馬（約450kg）で同じkg基準なのは不自然。
- **改良案**：体重比（%）で判定する。例：±1%以内は安定、-3%以上は減点。

**7. 連勝トレンドの二重加算**
- 「直近3走で連対2回以上（+5%）」と「直近2走連続連対（+10%）」は同時に当てはまりやすい。
- **改良案**：大きいほうだけを採用する（上限を決める）。

**8. 入手できないデータを前提にしたルール**
- 地方競馬ではレーティングがほとんど公表されない（案4）。
  ルール11「不明情報は捏造しない」とぶつかる。
- **改良案**：クラス・勝ち馬との着差・走破タイムの比較で代わりに判定する。

**9. 「騎手コンビ：A馬とB馬の騎手が同じ調教師」は意味が不明確**
- **改良案**：「同じ厩舎の2頭出し」に定義し直すか、削除する。

**10. WIN5の記述**
- WIN5はJRA（中央競馬）だけの馬券。また、馬連が当たっても1着馬は決まらないので、
  「馬連的中でWIN5も当選」は成り立たない。
- **改良案**：地方競馬中心なら、STEP18のWIN5部分は「JRA開催時のみ」とする。

**11. 出力例の小さな矛盾**
- 3番の馬名が「スーパーチヨコ」と「クロカゲパワー」の2つある。
- 馬連の買い目「3-9 / 9-3」は同じ組み合わせ（馬連は順番が関係ない）。

### 🟢 検証の進め方について

  **最低30レース程度ためてから**、的中率・回収率・印ごとの成績で判断する。
- 毎回 `keiba/logs/YYYY-MM-DD.md` に「予想 → 結果 → 検証」を記録する。

## 2026-10-14 実戦1日目で気づいたこと（仮説・累計30レースまでは未採用）

**A. 複合確度が平たくなりすぎて、10%の基準に届く組み合わせがない**
- 11頭立てでは組み合わせが55通りあり、計算式が能力差をほとんど反映しないため、最上位の組でも3.6〜6.0%にしかならなかった。
- 実際の馬連は、上位の組み合わせで15〜25%くらいの確率になることが多い。式の確率が低すぎる可能性が高い。
- **改良案**：1着率・2着率は「その馬の過去の率」ではなく、まずレース内の勝率に正規化する（全馬の合計を100%にする）。そのうえで、ハービル式で馬連の確率を出す（初回レビュー2番の残り部分）。

**B. 走数が少ない馬（2歳など）で2着率が0%になり、組み合わせの確率がゼロに近づく**
- 鎌倉記念では、無敗馬どうし（5番×9番など）の基礎スコアがほぼゼロになった。
- 今回は暫定で、`(回数 + 3/頭数) ÷ (走数 + 3)` の平滑化を使った。
- **改良案**：走数10未満の馬には、この平滑化を正式なルールにする。または2歳戦では、前走の着差・タイムを主に評価する。

**C. 朝の時点では、オッズ・馬場・当日の馬体重がわからない**
- 期待値の計算・馬場倍率・馬体重倍率が使えたのは、オッズがあった1レースだけだった。
- **改良案**：朝は印と候補だけを決めて、発走1時間前に「オッズ・馬体重による最終判定」をする2段階方式にする。

**D. Parallel Search の無料枠は、1日に出馬表4ページ前後で上限に達する**
- 園田の出馬表を取得できなかった。
- **改良案**：出馬表は1ページずつ取得し、full_content を使いすぎない。あるいは、対象レースを1日3レースまでにする。

## 2026-10-14 馬連が外れる原因の調査（`python3 keiba/diagnose.py`・過去526レース）

**結果**（前半285R＝調整用／後半241R＝確認用に分けて確認）
| 勝ち馬の予想方法 | 勝ち馬の対数損失（小さいほど良い） | 1位が勝つ率 | 馬連1位の的中率 | 回収率 |
|---|---|---|---|---|
| 全部均等（参考） | 2.307 | - | - | - |
| 全成績だけ（現行の元データ） | 2.153 | 23.6% | 8.2%（現行式は7.4%） | 59%（現行式51%） |
| 市場の単勝オッズ（1÷オッズ） | **1.558** | **45.1%** | **26.0%** | **83%** |
| 全成績20〜60%＋市場 | 1.57〜1.74（市場より悪化） | 41〜45% | 24〜25% | 78〜92%（前半99%・後半84%でぶれる） |
| 近走3走の着順10〜30%＋市場 | 1.60〜1.68（市場より悪化） | - | - | - |

**わかったこと（仮説ではなく、このデータでの事実）**
1. 全成績だけの式は、均等とほとんど変わらない（2.153 vs 2.307）。勝ち馬を選ぶ力が弱いので、馬連（1・2着の両方）はほぼ当たらない。
2. 予想の確率が小さい方に寄っていて（最大でも45%台、30%以上の馬は全期間で約60頭）、「明らかな本命」を見分けられない。市場は同じ区間に301頭を置き、実際の勝率53.8%と合っている。
3. 全成績・近走着順のどちらを市場に足しても、勝ち馬の予測は悪化した。市場のオッズに入っていない情報は、この2つからは見つからなかった。
4. 市場の1番人気に頼る馬連1位でも回収率は83%。払戻率（約75%）よりは高いが、100%未満。
5. 馬連オッズの推定式「単勝A×単勝B÷2.1」は、的中した組で実際の払戻が中央値で1.13倍高い。割る数を約1.86にするのが近い。

**修正の方向（提案・未実施）**
- A. 基礎確率を「市場の単勝オッズ」に変える（1÷オッズを合計1に正規化→ハービル式で馬連）。馬連の的中率が8%→26%になる見込み。ただし回収率は83%で、市場並みになるだけ。
- B. 自前の要素（全成績・近走・馬場・斤量などの倍率）は、「市場のオッズに足すと、別の期間で勝ち馬の予測が良くなるか」を確かめてから使う。確かめる前は掛けない。
- C. 馬連オッズの推定は、÷1.86に直すか、馬連オッズのページ（OddsUmLenFuku）から実際の値を取る。
- D. 検証期間を1〜2か月（5,000レース以上）に広げる。過去の出馬表と払戻は取得できる。
- E. 市場に入っていない情報（オッズの変化、当日の馬体重増減、騎手の乗り替わりなど）があるかを、同じ手順で一つずつ試す。

## 2026-10-14 「追加する／追加しない」の比べっこ（2,633レース・8/1〜10/13・`python3 keiba/ab_test.py`）
基準は「市場の単勝オッズだけ」。1要素ずつ足し、時間順の5分割で「前の期間で学習→次の期間で採点」（後ろ4分割）。
結果：**15要素すべて「追加しない」**（採用条件：誤差の2.5倍以上良くなり、4分割中3つ以上で良くなる）。詳細は `ab_report.md`。
- 良くなる方向だったのは、近3走の平均着順（+0.0018、誤差の1.0倍）だけ。偶然の範囲。
- 馬番（内→外）、この距離の1着率は、足すと**かえって悪化**（誤差の3倍）。
- 全要素を入れると、市場だけより悪化（-0.0109、2.8倍）＝過学習。
- 市場の勝率の指数の係数は1.045（市場は本命をごくわずかに低く見積もっている程度）。
→ 市場のオッズには、今回試した要素の情報がすでに含まれていると考えられる。
→ 次に試す案（E・常時調査）：オッズの変化（前日→締切）、騎手と調教師の組み合わせ、斤量の前走比、コース（内外）別の成績、前走からのクラス変化、直近の人気と着順のずれ（人気より走っていたか）。
