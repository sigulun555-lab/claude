# 地方競馬予想（ペーパー検証）

- `prompt.md` — 予想に使う統合プロンプト（ユーザー原文、改良は了承後に反映）
- `improvements.md` — 検証から出た改良案のログ
- `logs/YYYY-MM-DD.md` — 毎日の「予想 → 結果 → 検証」

## 毎日の流れ

1. 当日の地方競馬の開催場を確認（keiba.go.jp）
2. 対象レースの出馬表を取得し、`prompt.md` の STEP0〜20 で予想
3. レース後に結果・払戻を取得し、検証ルールに沿って ✓/✗ を記録
4. 予想と結果のズレの原因を `improvements.md` に追記

## 集計（30レースごとに見直し）

| 指標 | 内容 |
|---|---|
| ◎勝率・複勝率 | 本命の1着率・3着内率 |
| 馬連的中率 | 推奨馬連の的中数 ÷ 推奨数 |
| 回収率 | 払戻合計 ÷ 購入合計（1点100円換算） |

※ 実際の馬券購入ではなく、記録上の検証です。
