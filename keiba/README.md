# 地方競馬予想（ペーパー検証）

- `prompt.md` — 予想に使う統合プロンプト（ユーザー原文、改良は了承後に反映）
- `improvements.md` — 検証から出た改良案のログ
- `logs/YYYY-MM-DD.md` — 毎日の「予想 → 結果 → 検証」

## 毎日の流れ

1. 当日の地方競馬の開催場を確認（keiba.go.jp）
2. 対象レースの出馬表を取得し、`prompt.md` の STEP0〜20 で予想
3. レース後に結果・払戻を取得し、検証ルールに沿って ✓/✗ を記録
4. 予想と結果のズレの原因を `improvements.md` に追記

## 集計（30レースごとに見直し）

| 指標 | 内容 |
|---|---|
| ◎勝率・複勝率 | 本命の1着率・3着内率 |
| 馬連的中率 | 推奨馬連の的中数 ÷ 推奨数 |
| 回収率 | 払戻合計 ÷ 購入合計（1点100円換算） |

※ 実際の馬券購入ではなく、記録上の検証です。

**最優先はばんえい**（2026-10-17 ユーザー指示）。すべての報告・集計で、ばんえいを先頭に出し、平地は別枠で扱う。

## 仕組み（2026-10-14 改善版⑤）

| ファイル | 役割 |
|---|---|
| `history.py` | 過去と当日の全レース（出馬表・最終オッズ・払戻）を `data/history.jsonl` に貯める |
| `ab_test.py` | 「市場のオッズだけ」に要素を1つずつ足して、別の期間で勝ち馬の予想が良くなるか確かめる。結果は `ab_report.md`、採用した要素は `model.json` |
| `paper.py` | 締切時オッズで、全レースの馬連・馬単を3つの方法（旧式／市場／追加）で記録する。累計は `python3 keiba/paper.py summary` |
| `odds_snapshot.py` | 朝・昼・夕（9:52・13:27・17:27）にその時点の単勝オッズを全レース分 `data/odds_snapshots.jsonl` に保存する |
| `odds_move_test.py` | 「発走60分以上前→締切時」のオッズの変化を足すと予想が良くなるか確かめる（300レース・6日分たまったら判定。`ab_test.py` から呼ばれる） |
| `diagnose.py` / `backtest.py` | 馬連が外れる原因の調査／過去の的中率・回収率の確認 |
| `screen.py` | 旧式（全成績だけ）のスクリーニング。比較用に残してある |

記録：`logs/<日付>_paper.csv`（上位10点の中身）、`logs/paper_summary.csv`（日別の集計）。

## 的中確率50%以上の拾い出し（`picks.py`）
出走表を取ったあとに実行し、市場の単勝オッズから計算した「的中する確率が50%以上」の買い目（単勝・複勝・馬連・馬単）を拾って報告する（朝と夕方のルーチンに組み込み済み）。夜に `python3 -I keiba/picks.py settle` で、予想の確率と実際の的中率・回収率を比べる。お金は賭けない記録上の検証。
